## 해석
1. **길이 교란은 주로 report_content 양성에서 생깁니다.** report_content를 빼면 점수와 길이의 상관이 0.46에서 0.13으로 떨어집니다. 길이+step 기준선은 0.438로 우연 수준 아래가 됩니다.
2. **행동형 위반에서는 L16 신호가 길이와 무관하게 강합니다.** AUROC 0.785이고, 길이 성분을 제거해도 0.803이며, 길이 층화로도 0.766입니다.
3. **다만 행동형 신호의 상당 부분이 결함 기인 양성(S10, S48/S59 등)에서 옵니다.** 이를 빼면 0.627이고 CI가 넓습니다(양성 23개). 이것이 결함이 만든 인공 신호인지, 절차 생략이라는 정상적인 위반 패턴인지는 이 데이터로 구분할 수 없습니다.
4. **이 결과는 train CV 탐색 결과입니다.** 같은 데이터에 조건 5개를 비교했으므로 다중 비교에 따른 낙관 편향이 있습니다. 성공 게이트 판정(G1–G5)을 대신할 수 없으며, 새로 수집한 데이터의 validation으로 확인해야 합니다.
